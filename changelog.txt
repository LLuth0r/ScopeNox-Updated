Below is the changelog for ScopeNox by LLuth0r

1.3.0 - New Projector alignment setting (Skin Settings -> Scope): Centre / Top / Bottom. For projectors whose zoom is anchored
        at the top or bottom edge of the picture, Top/Bottom move the whole skin AND every movie to that edge of the frame,
        so only small adjustments are needed in Video calibration. Centre (default) works as before.
        No more jump when a movie starts: the picture is positioned before it's shown.
        New "Keep subtitles in the scope frame" setting (on by default): subtitles are placed just above the bottom of the
        scope frame for your alignment and scope format.
        Subtitle up/down buttons work again in Kodi 21 (1% per press, remembered).
        AutoZoom now also applies to the next item in a playlist (next episode, Live TV channel change).
        AutoZoom's fit and the video shift account for non-16:9 screens.

1.2.4 -New Save zoom button on the playback OSD: set any zoom (e.g. 0.81 with Kodi's zoom slider for an IMAX 1.90 release
        stored in a 16:9 frame) and press Save zoom to remember it for that movie. The button shows a bar while one is saved.
        Playback OSD buttons are smaller (84px) so the whole row fits on screen, and every icon is now properly centred.
        Video calibration arrows, subtitle bar and reset icon are visible again (they were hidden behind the scope bars
        and drawn transparent).
        Focus highlight bars now show in the info screen details list, select dialogs and the Add-on Status window.
        Added tools/genosd.ps1, the generator for the playback OSD button icons.

1.2.3 -AutoZoom remembers full size per movie: press zoom in once on a scope movie with baked-in black bars (reported as 1.78)
        and it plays at 1.00 from then on. Zoom out forgets it again. Works with PlexKodiConnect (saved by IMDb/TMDb id, not file path).
        The zoom-in button shows an "on" bar while the playing movie has a remembered zoom.
        New "Clear saved AutoZoom settings" option in Skin Settings -> Scope.
        AutoZoom now sets the exact zoom directly (no more zoom slider flashing) and fits to the stream's actual aspect ratio.
        AutoZoom and the zoom buttons run from a script inside the skin (scripts/autozoom.py); nothing extra to install.

1.2.2 -Fixed AutoZoom zooming movies out too far on replay (e.g. 0.54 instead of 0.76). It now sets an exact zoom every time.
        Zoom in/out and subtitle up/down buttons on the playback OSD are built into the skin; ScopeNox-Tools is no longer needed.
        Zoom out fits 16:9 inside the scope frame (0.74 / 0.76); zoom in goes back to 1.00 for scope movies with baked-in bars.
        New thin-ring playback OSD buttons that follow the theme colour; button row centred on the OSD bar.
        Actor portraits and names on the info screen now fit inside the scope frame (5 across).
        Background can be your own image or a folder slideshow, with a selectable slideshow interval.
        Fixed the default background (was pointing at a removed image).
        Fixed wrapped genres being covered by Runtime in the LowList and TriPanel views.
        Video library media flags show again; fixed the Add-on Status window layout and the debug overlay.
        Fixed skin errors in kodi.log. Replaced leftover "Aeon Nox" wording in the skin settings.
        Removed the bundled ScopeNox-Tools add-on; README updated.

1.2.1 -AutoZoom is now built into the skin; script.scopenox-autozoom is no longer needed.
        Zoom amount is based on the video stream's aspect ratio (1.33 - 2.19) and the selected scope format
        (2.35 or 2.40), instead of a fixed amount for everything. Runs once per file.
        Scope mask detection now covers any stream 2.20 and wider (e.g. 2.39), not just a fixed list.
        Added a PPI (Player Process Info) button to the playback OSD.
        PPI screen moved inside the scope frame so it is no longer cropped on zoomed CIH screens.
        PPI now shows the HDR type (Dolby Vision, HDR10, HLG or SDR) and the output display mode.
